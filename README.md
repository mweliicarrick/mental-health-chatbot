# 🧠 MindEase AI – Mental Health Chatbot

MindEase AI is a modern mental wellness chatbot built with Python and tkinter.  
It is designed to provide supportive conversations, emotional check-ins, calming exercises, and therapist-style interactions through a clean futuristic desktop interface.

---

# ✨ Features

- 💬 Human-like conversations
- 🧠 Emotion detection
- ❤️ Therapist-style responses
- 🌿 Breathing exercises
- 📖 Journal prompts
- 💡 Motivational affirmations
- ⚠️ Crisis keyword detection
- 🧾 Chat logging system
- 🎨 Modern black & neon-green GUI
- 🗣️ Context-aware follow-up questions
- 😊 Friendly conversational style

---

# 📸 Preview

MindEase AI uses a modern dark-mode interface inspired by futuristic AI assistants and messaging apps.

# 🚀 Installation

## 1️⃣ Clone or Download the Project

Download the project ZIP or clone it using Git.

---

## 2️⃣ Install Required Libraries

Open terminal inside the project folder and run:

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Chatbot

Run the application using:

```bash
python main.py
```

The MindEase AI desktop window should open automatically.

---

# 🧠 How It Works

The chatbot:
- analyzes user emotions
- detects stress/sadness
- generates supportive responses
- asks meaningful follow-up questions
- provides calming mental wellness activities

The goal is to create a conversational AI companion that feels supportive, engaging, and emotionally aware.
